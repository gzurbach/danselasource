# danselasource.fr

The website for Danse la Source, a gîte in Trézelles, in the Allier.

Six pages — three in French, three in English. Plain HTML and CSS, generated by
a small Python script. No framework, no dependencies, no build tooling beyond
Python 3.

## Editing

Text, photo captions and the list of nearby attractions all live in
[`content.py`](content.py). Edit it, then:

```bash
python3 build.py
```

That regenerates `dist/`, which is the site. To preview it locally:

```bash
python3 -m http.server 4321 --directory dist
```

Photos live in `assets/img/`: `full/` is shown in the lightbox, `thumb/` in the
grid. To add one, put both sizes in with the same filename and add an entry to
the relevant gallery list in `content.py`.

Filenames say what they are — `gite-cuisine`, `studio-lit`, or the place name
for the attractions. `archive/` holds older photos no page uses; it stays in the
repo but is never published.

## Pages

Each language lives in its own folder, French at the root.

| URL | |
|---|---|
| `/` | French home |
| `/fr/le-gite` | The cottage |
| `/fr/loisirs` | Nearby attractions |
| `/en/` | English home |
| `/en/cottage` | The cottage |
| `/en/nearby-attractions` | Nearby attractions |

Nothing else is served. The old Squarespace URLs are gone rather than
redirected, so anything still pointing at them lands on `404.html`, which
offers both home pages in both languages.

## Deployment

Hosted on GitHub Pages. Pushing to `main` runs
[the workflow](.github/workflows/deploy.yml), which builds the site and
publishes `dist/`.

The canonical domain is the apex, `danselasource.fr`; `www` redirects to it.
DNS is at Gandi:

```
@      A      185.199.108.153
@      A      185.199.109.153
@      A      185.199.110.153
@      A      185.199.111.153
www    CNAME  gzurbach.github.io.
```

GitHub matches the request to this repository using the `CNAME` file, which
`build.py` writes from the domain set in `content.py`.
